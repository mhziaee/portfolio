# Run the portfolio locally

## Requirements

- Node.js 22.13 or newer
- npm (included with Node.js)

## Start the site

1. Extract the ZIP file.
2. Open Terminal in the extracted `Hossein-Ziaee-Portfolio` folder.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the local site:

   ```bash
   npm run dev
   ```

5. Open the local address shown in Terminal, usually `http://localhost:5173`.

## Verify a production build

```bash
npm run build
```

The portfolio does not require environment variables, a database, or an external service to run locally.
